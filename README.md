# 🍷 Regression Analysis: Wine Quality Prediction

A **data science project** developed to analyze and predict **wine quality** based on **physicochemical tests**. This project demonstrates the application of **Ridge Regression** and statistical modeling as part of the **Analisis Multivariat coursework (Class B083)**.

The analysis explores the relationship between chemical properties—such as **acidity, sugar, and pH**—and the **sensory quality of wine**.

## 🚀 Key Features

### 🧹 Data Processing

* **Dataset Input**: Loads and inspects the physicochemical attributes of the wine dataset.
* **Feature Selection**: Focuses on key variables such as:

  * Fixed Acidity
  * Volatile Acidity
  * Citric Acid
  * Residual Sugar

### 📉 Regression Modeling

* **Ridge Regression**: Applied to handle multicollinearity and reduce overfitting.
* **Model Training**: Fits the regression model to training data to learn feature–quality relationships.

### 📊 Model Evaluation

* **Performance Metrics**:

  * R-Squared (R²)
  * Adjusted R-Squared
* **Coefficient Analysis**: Extracts and interprets regression coefficients for each chemical feature.
* **Equation Generation**: Automatically generates the final linear regression equation for wine quality prediction.
